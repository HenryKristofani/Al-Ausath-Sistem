# DELETE /api/data-master/jadwal-pembelajaran/{id}

Auth: `sanctum`

Endpoint ini dipakai untuk menghapus jadwal pembelajaran.

## Contoh request

```
DELETE /api/data-master/jadwal-pembelajaran/10
```

## Contoh response sukses

```json
{
  "message": "Data jadwal pembelajaran berhasil dihapus."
}
```
